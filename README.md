Welcome to my Python learning repository! While basic syntax provides the tools, this space is dedicated to the core logic, algorithms, and structural architecture of software development. This repo documents my journey from foundational scripting to complex data structures and Object-Oriented Programming (OOP) following freeCodeCamp standards.

## 📌 Project Overview

The goal of this repository is to bridge the gap between simple code snippets and scalable software design. It tracks my progress in mastering control flow, modular design, object-oriented paradigms, and algorithmic problem-solving.

## 📂 Structure

* **Theory & Docs:** Deep dives into Python mechanics, standard libraries, and execution logic.
* **Projects:** Functional scripts and real-world tools (Bill Splitters, Ciphers, Converters).

## 🛠️ What's Inside?

* **Control Flow & Types:** Deep understanding of dynamic typing, string formatting, conditional logic, and loop iterations.
* **Data Structures:** Operations using Lists, Tuples, Dictionaries, Sets, and built-in methods.
* **Functions & Scope:** Modularizing code with parameters, return statements, scope resolution, and lambda functions.
* **Object-Oriented Programming:** Designing clean classes, encapsulation, methods, and inheritance hierarchies.
* **Error & Exception Handling:** Writing resilient code using `try`/`except` blocks, custom assertions, and defensive programming.

## 🚀 How to Use This

* **Start with Theory:** Look into the `Documentation/` folder to understand Python execution mechanics, dynamic binding, and scope rules.
* **Explore Projects:** Navigate to the `Projects/` folder to see how these theories transform raw logic into functional applications.
